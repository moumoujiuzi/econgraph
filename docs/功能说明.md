# EconGraph · 经济学函数绘图台 v2

离线、免安装的桌面绘图工具：四种曲线类型 + 符号计算 + 数值分析 + 数据拟合 + TikZ 导出。
给经济学学生和只做平面分析的数学爱好者用。

- 双击 `EconGraph.exe` 即开，不联网、不装运行时。
- 27 个模板（经济学 / 金融 / 数学 / 动态四类）。
- 命令行可被脚本调用，能直接出 PNG 或 TikZ。

## 零、顶部命令栏

窗口最上方是输入栏，敲回车就执行，不用去左边找：

| 输入 | 效果 |
|---|---|
| `sin(x)` | 直接画出 y = sin(x) |
| `x^2 - 3*x + 2` | 画多项式 |
| `2 + 3*4` | 算出 14，并画一条 y = 14 的参考线 |
| `x^2 + y^2 = 4` | 识别为隐函数，画圆 |
| `(cos(t), sin(t))` | 参数曲线 |
| `taylor(sin(x), 7)` | 7 阶泰勒多项式叠在原函数上 |
| `series(sin(n*x)/n, 20)` | 级数前 20 项的部分和 |
| `nested(sqrt(2 + R), 10)` | 嵌套根式叠 10 层 |
| `deriv(sin(x), 3)` | 画 0–3 阶导 |
| `add(sin(x), x^2)` | **函数相加**：同时画 f、g 与 f + g，展示条写出合并后的表达式 |
| `preset(islm)` | 切到某个模板 |
| `clear` | 清掉命令画出的东西 |

输入栏下方还有一条**表达式展示条**：用可读形式写出当前函数（如 y = sin(x) + x²），相加时还会注明哪条是分函数、哪条是和。

输入时右侧会实时预览解析结果（“将绘制 y = …”“= 14”“隐函数”），↑/↓ 翻历史，Esc 清空。

**边打边画**：不用按回车，输入到哪画到哪，并自动切到「自定义函数」画布。
打到一半（比如 `x^2+sin`）时会**保留上一段完整表达式**（仍显示 y = x²），
等 `(` 或 `x` 补上、表达式变完整了再更新——不会因为一个未闭合的括号把图清空。

- `x的平方加sin`　→ 仍显示 y = x²（sin 还没参数）
- `x的平方加sinx`　→ 变成 y = x² + sin(x)
- `x的平方加sinx的立方`　→ 变成 y = x² + sin(x)³
侧栏的自定义曲线功能完全保留，两者互不冲突：命令画出的曲线带 `cmd` 标记，再次输入会替换它而不是越堆越多。

## 零点五、中文和符号也能直接输入

顶栏、侧栏、求和框里的输入都会先经过一层「规范化」，因此下面这些写法都认得：

| 你这么写 | 自动转成 | 说明 |
|---|---|---|
| `五分之三` | `(3)/(5)` | 中文分数，也支持 `x分之1` |
| `x的十次方` | `x^10` | 也支持 `x的平方`、`x的立方` |
| `根号x 加 三` | `sqrt(x)+3` | `根号`、`加/减/乘/除` 都识别 |
| `x² + π` | `x^2+pi` | 上标、希腊字母 |
| `３＋４` | `3+4` | 全角转半角 |
| `∞` | `Infinity` | 也可写 `inf`、`无穷`、`无穷大` |

顶栏输入时，右侧提示会显示“识别为 …”，能看见它到底被读成了什么。

**按回车后，顶栏里的中文会被改写成标准式**（不是只改展示条）：

```
输入   3的x次方加e的（x分之一）次方
回车后 3^x+exp((1)/(x))
```

改写规则的要紧之处是「的…次方」的**底数和指数都按复合表达式处理**：

| 输入 | 识别为 | 说明 |
|---|---|---|
| `e的x分之一次方` | `exp(1/x)` | 底数 e、指数 1/x |
| `e乘（二分之一的x次方）` | `e·(1/2)^x` | 括号先算，指数作用在 1/2 上 |
| `x的十次方` | `x^10` | 中文数字 |
| `(x+1)的平方` | `(x+1)^2` | 括号底数 |

**∞ 的输入方式**：中文输入法打 `wuxiong`/`wuqiong`、或符号面板里找 `∞`，直接粘进框里就行；
求和上限填 `∞` 会自动按 400 项近似（面板会标“∞ (按400项)”），因为机器不可能真加无穷项。

## 零点八、视图缩放与坐标轴

左侧「视图范围」现在只有一个**缩放滑杆**（取代原来的四个数字框）：

- 拖白色圆点，10% – 400%，像浏览器缩放一样，中心保持不动
- 右侧实时显示百分比，`复位` 一键回到 100%
- 滚轮缩放、拖拽平移同样可用，滑杆会跟着变
- 画布随窗口大小自适应（最大化后铺满，不再留白）

坐标轴**自适应**：0 在视图范围内时穿过原点（y = x² 的顶点正好落在轴上），
0 不在范围内时自动贴到边上。想强制贴边，勾下面的「坐标轴强制贴边」。

## 一、四种曲线类型

| 类型 | 写法 | 能画什么 |
|---|---|---|
| `y = f(x)` | `0.8*Y + 200` | 绝大多数教材函数 |
| `F(x, y) = 0` | `x - (100 + 0.75*(x-100) + 200 - 25*y + G)` | **IS-LM、等产量线、无差异曲线、相图零斜线** |
| 参数方程 | `x = 2*cos(t)`，`y = sin(2*t)` | 相轨迹、李萨如、摆线 |
| 极坐标 | `r = 1 + cos(theta)` | 心形线、玫瑰线、螺线 |

隐函数用 marching squares 求解，分辨率随画布自适应（约 5 px 一格）。

## 二、数值工具（∑ 按钮）

| 工具 | 说明 |
|---|---|
| **求根 / 交点** | 区间扫描 + 二分；选第二条曲线即求两曲线交点 |
| **切线** | 数值求导，画出切线并给出方程（讲 MRS / MRTS / 边际量） |
| **定积分** | 复合辛普森，可把面积填到图上（消费者剩余、无谓损失） |
| **黎曼和** | 左/右/中点矩形，n 可调，显示与精确积分的误差 |
| **迭代 / 蛛网** | `xₜ₊₁ = f(xₜ)` 的蛛网图，收敛/发散一眼可见 |
| **数据拟合** | 粘贴两列数据 → OLS 回归、R²、散点 + 回归线 |

## 三、动态系统（方向场）

二维自治系统 `ẋ = f(x,y)`、`ẏ = g(x,y)` 的完整分析，是常微分方程与线性代数的直接延续：

- **方向场**：网格上画箭头，粗细/深浅随速度变化
- **零斜线**：`ẋ=0` 与 `ẏ=0` 直接用隐函数引擎画出
- **平衡点**：网格扫描 + 牛顿迭代求解，自动去重
- **稳定性**：数值雅可比 → 特征值 → 判为稳定结点 / 不稳定结点 / 鞍点 / 稳定焦点 / 不稳定焦点 / 中心
- **轨线**：RK4 积分，预置若干初值；**点击画布任意位置**可现场加一条轨线

内置五个系统：Lotka–Volterra（中心）、SIR 传染病、鞍点、稳定焦点（阻尼振荡）、
IS–LM 调整动态（`Ẏ = α(AD−Y)`，`ṙ = β(L−M)`）。

## 三、数学工具（ƒ 按钮）

符号计算，结果都能一键画到图上：

- **高阶导数**：1–6 阶符号求导，输出化简表达式
- **泰勒展开**：任意展开点、1–12 阶，给出 `f⁽ᵏ⁾(x₀)/k!` 系数表与多项式，可画多项式或误差曲线
- **二项式定理**：`(a+b)ⁿ` 逐项展开 + 帕斯卡三角
- **莱布尼茨公式**：`(uv)⁽ⁿ⁾ = Σ C(n,k)u⁽ᵏ⁾v⁽ⁿ⁻ᵏ⁾` 逐项合并

## 三·五、级数工坊（∑ 按钮）

三张可以「点一下长一项」的工作台，结果实时叠在图上：

| 标签页 | 操作 | 效果 |
|---|---|---|
| **泰勒逐项** | `+1 阶` / `-1 阶` / `+5 阶` | 每点一次多一项，红色曲线立刻变成新的 Pₙ，下方给出多项式与系数 |
| **求和 Σ** | 左边一个标准 Σ：上面填上限、下面填 `n =` 起始，右边空白框填通项 | 不用会打 Σ，框里只写通项即可；上下限单独填，实时出图 |
| **导数逐阶** | `+1 阶` / `-1 阶` | 每点一次多画一阶导，每阶一种颜色，下方列出各阶表达式 |

级数默认通项 `sin(n*x)/n`，从 N=1 的正弦逐步变形成锯齿波——就是“无穷级数收敛到另一个函数”的过程；
方波换成 `sin((2n-1)*x)/(2n-1)`。也可填 `x^n` 看几何级数。

「级数工坊」不再盖住画布：

- 右上角 × 关闭；拖动不会影响其他面板

## 三·六、嵌套根式（同一个面板的第四个标签）

一层套一层的式子。你只写**每一层长什么样**（用 `R` 表示里面那一层），程序从里往外叠 N 层：

| 写法 | 每一层的模板 | 最里面 `R₀` | 极限 |
|---|---|---|---|
| 经典 | `sqrt(2 + R)` | 0 | 2 |
| 函数型 | `sqrt(x + R)` | 0 | `(1+√(1+4x))/2` |
| 黄金比 | `sqrt(1 + R)` | 0 | 1.618… |
| 拉马努金 | `sqrt(1 + k*R)` | 1 | 3 |
| 连分数 | `1 + 1/(1 + R)` | 1 | 1.618… |
| 带参数 | `sqrt(a + R)` | 0 | 解 √a 的方程 |

面板里三个字母：

- **R** —— 里面那一层的计算结果（写模板时当成一个整体占位）
- **k** —— 这是第几层（1、2、3…），只有各层系数不同时才用得上
- **N** —— 一共往外叠几层，也就是“层数”

`sqrt` 就是根号 √，也可以直接敲 `√`。
**R₀**（最里面一层）是没有更内层时 R 的取值：`√(2+√(2+…))` 填 0、连分数填 1；
层数够多时填 0 还是 1 几乎不影响结果，它只决定“从哪儿开始叠”。

面板最上方会把这个式子**展开显示出来**，而且分成两行：

`
无穷形式（跟 R₀ 无关）：√(3 + √(3 + √(3 + …)))
最里面那一层（跟着 R₀ 变）：√(3 + 1)   ← R₀ = 1
`

改 R₀ 时，第二行和下面的逐层数值会立即变化；无穷形式本身与 R₀ 无关，所以那一行不动。
再往下是逐层数值（1 层、2 层、3 层…）、逐层展开（每加一层外面多套一个根号）和 80 层的参考值。
图上同时画当前曲线和一条灰色的“极限参考线”。点 `+1 层` 就能看着它收敛。

**经济学（12）**

| id | 名称 | 关键结论 |
|---|---|---|
| `consumption` | 凯恩斯消费函数 | 收支相抵点 `Y* = a/(1−b)` |

| `indifference` | 无差异曲线与预算线 | 切点 `X*=I/2Px` |
| `cost` | 短期成本曲线 | MC 过 ATC 最低点 |

| `solow` | **索洛模型** | 稳态 `k* = (s/(n+δ))²` |

| `lorenz` | **洛伦兹曲线** | `Gini = 1 − 2∫L` |

## 七、表达式语法

支持 `+ - * / ^ %`、括号、`pi`/`e`、`sin cos tan asin acos atan sinh cosh tanh sqrt abs exp ln log log2 floor ceil round sign min max pow`。

- 可写完整方程：`C = 200 + 0.8*Y`
- 数字与字母可省乘号：`0.8Y`、`2sqrt(x)`
- 字母与字母之间要写 `*`
- `^` 右结合：`2^3^2 = 512`

## 十、已知限制

- 隐函数的 TikZ 导出是线段拼接（不是解析曲线），文件会略大。
- 隐函数在极陡处可能出现断点（marching squares 的固有分辨率限制）。
- 符号求导不支持 `min/max/floor/ceil`，会给出提示而不是崩溃。
- 泰勒/二项式系数上限 12 阶，避免表达式爆炸。
- 只做平面（2D）分析，不支持 3D 曲面。
