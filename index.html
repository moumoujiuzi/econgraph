一层套一层的式子，比如 √(2+√(2+√(2+…)))。你只要写每一层长什么样， 程序从里往外套 N 层给你看，N 越大越接近真实值。

R　＝ 里面那一层算出来的结果（写模板时先当成一个整体）
k　＝ 这是第几层（1、2、3…），只有各层系数不同时才用得上
N　＝ 一共往外叠几层，就是右边的层数

√ 形式：√(2 + R)

R₀ 是什么：叠到最里面、没有更内层时 R 取的值。 √(2+√(2+…)) 一般填 0，连分数 1+1/(1+…) 一般填 1。 只要层数够多，填 0 还是 1 对结果几乎没影响，它只决定"从哪儿开始叠"。

想换成别的形状？直接改上面那一行就行，例如 1 + 1/(1 + R)、sqrt(a + R)、sqrt(1 + k*R)； sqrt 就是 √，R 代表里面那层。
